# Trained Model

`speechDenoisingBiLSTM_v7.mat` is the supplied final v7 MATLAB model artifact.

It stores the trained network and the normalization/configuration information required by the final inference script, including `featMean`, `featStd`, STFT configuration, sequence length, hidden-unit count, and fully connected layer size.

The model is an inference artifact and is provided as-is from the supplied project results.
